## 一、 基本概念厘清

在深入学习之前，我们需要先明确几个极易混淆的基本术语：

- **数据**：对客观事物的符号表示（如数字、图像、声音等）。
- **数据元素**：数据的基本单位（例如：一条学生的信息记录）。
- **数据项**：构成数据元素的不可分割的最小单位。一个数据元素可由若干个数据项组成（例如：学号、姓名、性别等）。
- **数据对象**：具有相同性质的数据元素的集合。
- **数据结构**：相互之间存在一种或多种特定关系的数据元素的集合。可以形式化表示为 `Data_Structure = (D, S)`。

## 二、 数据结构的"三要素"

数据结构包括三方面的内容：**逻辑结构、存储结构和数据的运算**。

### 逻辑结构

逻辑结构描述的是数据元素之间的逻辑关系，独立于计算机：

- **线性结构**：数据元素之间是一对一的关系，包括一般线性表、栈、队列、串、数组。
- **非线性结构**：
  - **集合**：数据元素除了同属一个集合外，无其他关系。
  - **树形结构**：一对多关系。
  - **图形结构或网状结构**：多对多关系。

### 存储结构（物理结构）

存储结构是逻辑结构在计算机内存中的实际映射方式，主要分为四种：

| 存储方式 | 核心描述 |
| :--- | :--- |
| **顺序存储** | 逻辑上相邻的元素，存储在物理位置也相邻的存储单元中。（如 Java 中的数组） |
| **链式存储** | 借助指示元素存储地址的指针来连接逻辑相邻的元素。 |
| **索引存储** | 建立附加的索引表，包含索引项（关键字、地址）。 |
| **散列存储** | 哈希（Hash）存储，通过散列函数将关键字直接映射为存储地址。 |

## 三、 算法基础与效率度量

**算法**是对特定问题求解步骤的一种描述。一个合格的算法必须具备以下 5 个特性：

1. **有穷性**：有穷步骤、有穷时间。
2. **确定性**：每一步都有确切的定义，无歧义。
3. **可行性**：每一步都能通过执行有限次基本操作来实现。
4. **输入**：有零个或多个输入。
5. **输出**：有一个或多个输出。

通常设计一个"好"的算法应考虑达到以下目标：**正确性、可读性、健壮性、效率与低存储量需求**。

### 算法的效率度量

算法分析的根本目的是：**分析算法的效率以求改进**。我们通常从时间复杂度和空间复杂度来衡量。

- **频度**：该语句在算法中被重复执行的次数。
- 算法中所有语句的频度之和记为 `T(n)`，时间复杂度即 `T(n) = O(f(n))`。

#### 复杂度推导规则

- **加法规则**：`T(n) = T1(n) + T2(n) = O(f(n)) + O(g(n)) = O(max(f(n), g(n)))`。多个代码块并列时，取最大复杂度。
- **乘法规则**：`T(n) = T1(n) × T2(n) = O(f(n)) × O(g(n)) = O(f(n) × g(n))`。嵌套代码（如双重循环）取乘积。

#### 常见的渐近时间复杂度（由低到高）

```text
O(1) < O(log₂n) < O(n) < O(n·log₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)
```

## 四、 线性表与顺序表

### 线性表的定义

**线性表**是具有相同数据类型的 `n (n ≥ 0)` 个数据元素的有限序列：

```text
L = (a1, a2, ..., ai, ai+1, ..., an)
```

核心特性：

- 除第一个元素外，每个元素有且仅有一个**直接前驱**。
- 除最后一个元素外，每个元素有且仅有一个**直接后继**。

**基本操作（伪代码）：**

`InitList(&L)`（初始化）、`Length(L)`（求表长）、`LocateElem(L, e)`（按值查找）、`GetElem(L, i)`（按位查找）、`ListInsert(&L, i, e)`（插入）、`ListDelete(&L, i, &e)`（删除）、`PrintList(L)`（输出）、`Empty(L)`（判空）、`DestroyList(&L)`（销毁）。

### 顺序表（顺序存储的线性表）

顺序表用一组地址连续的存储单元依次存储数据元素。它的核心特点如下：

1. **随机存取**：最主要的特点。通过首地址和元素序号可在 `O(1)` 时间内找到指定元素。
2. **存储密度高**：每个结点只存储数据元素，没有额外的指针开销。
3. **物理相邻**：逻辑上相邻的元素物理上也相邻，因此**插入和删除操作需要移动大量元素**。

#### 内存地址计算

假设第一个元素 `a1` 的地址为 `LOC(A)`，每个元素占用的空间为 `sizeof(ElemType)`，那么第 `i` 个元素 `ai` 的内存地址计算：

```text
LOC(ai) = LOC(A) + sizeof(ElemType) * (i - 1)
```

*（注：这解释了为什么数组下标从 0 开始。在 Java 中，`ArrayList` 底层基于数组实现，高效查询的根基就在于此。）*

#### C 语言中的结构定义

**① 静态分配**（大小固定）：

```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];
    int length;
} SqList;
```

**② 动态分配**（大小可扩展）：

```c
#define InitSize 100
typedef struct {
    ElemType *data; // 指向动态分配数组的指针
    int MaxSize, length;
} SeqList;

// 动态分配语句：
L.data = (ElemType*) malloc (sizeof(ElemType) * InitSize);
```

> **后端思维延伸：** 这里的 C 语言动态分配，本质上是在内存中开辟一块更大的存储空间来替换原来的空间。完美对应了 Java `ArrayList` 源码中，在元素满时调用 `Arrays.copyOf` 进行动态扩容的底层思想。

## 五、 链式存储：链表家族

针对顺序表"插入删除需要移动大量元素"的痛点，链表（链式存储的线性表）应运而生。

### 单链表

单链表的结点结构分为两部分：`| data | next |`。`data` 存数据，`next` 存指向下一个结点的指针。

C 语言结构描述：

```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

### 双链表

为了弥补单链表"只能单向遍历"的缺点，双链表结点中引入了两个指针 `prior` 和 `next`，分别指向其前驱结点和后继结点。

结构图示：

```text
<- prior | data | next ->
```

C 语言结构描述：

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```

### 循环链表

**循环单链表**：尾结点的 `next` 指针不再为 `null`，而是指回头结点（或首元结点），形成一个环。

**循环双链表**：在双链表的基础上，头结点的 `prior` 指向尾结点，尾结点的 `next` 指向头结点。实现真正的双向闭环。

*（注：在 Java 中，`LinkedList` 的底层结构就是一个经典的双向链表。）*
